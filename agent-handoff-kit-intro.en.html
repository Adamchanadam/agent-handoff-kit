What carries forward?

Without a handoff, you often have to repeat context, find files again and remind the AI which approaches were already tried. With the tool, important context stays in the project. You still set requirements and make decisions; the AI organizes and checks the work.

Pick up the work without retelling everything.

Long tasks can lose past decisions, your corrections and unfinished items between conversations. The tool helps the AI save them. Next time, it reads the full handoff before explaining where things stand.

Resume work →

Help the next AI find important files.

New articles, reference PDFs and work plans should not live only in one conversation. The tool records what files are for, when to read them and what related material needs updating, reducing missed sources and wrong-version use.

Check file connections →

Find the reasons months later.

Alongside current progress, the tool keeps important decisions, their reasons and work records. Ask “Why did we choose this?” and the AI can trace the saved evidence. Long records are organized and archived as needed, without rereading everything every time.

Switch tools, keep the same project.

Open the same folder in a supported AI tool to reuse saved handoffs and working requirements. Project content is handled separately from official tool files; upgrades preserve custom changes and stop at conflicts.

You describe the goal. The AI adapts the work.

You do not select work modes or memorize rules. Describe the result you want; the AI applies the relevant approach and asks only when missing information affects the outcome.

Build pages, write code or fix problems

Read relevant files, preserve existing changes and check the actual result afterward.

Distinguish sources, notes and deliverables; verify connections and permissions, then read back any writes.

First time? Give this sentence to your AI.

Open your project folder in your AI tool and paste the sentence below. The AI confirms the folder, installs or upgrades, then checks the result. You do not choose the installation commands.

Read https://adamchanadam.github.io/agent-handoff-kit/agent-handoff-kit-ai-install.en.html and install or upgrade Agent Handoff Kit in this project folder.

You need an AI tool with read and write access to your project folder, plus Node.js 18 or later. Web chat without folder access is not supported; ask the AI to check if unsure. Use the same sentence for older versions or existing AI work files.

Stay informed while you work.

The AI must read the full handoff before claiming it has resumed. Start on its own reports the current state; work begins when you give a task. Wrapping up can save unfinished work without marking the whole project complete.

Before uploading, publishing, deleting important data or changing access, the AI must explain the effects and obtain the required approval. Passwords and secret keys must not enter handoff records. The tool’s rules and checks help; they cannot guarantee an AI will never make a mistake.

Protect your data and other work.

After using external tools, the AI should close only temporary processes it can confirm belong to this task. If it is unclear which task a process belongs to, it asks first to avoid interrupting other work. Missing permissions or locked files must be reported, not bypassed.
