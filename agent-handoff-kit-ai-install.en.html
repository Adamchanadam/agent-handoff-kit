AI-readable install page · v0.3.43

Install or upgrade safely.

This page is for an AI agent that can read and write the local project folder and run terminal commands. The user should not need to choose a command or diagnose a conflict.

Version note: this source page can be ahead of the published npm package; @latest means the version currently available from the npm registry.

Read https://adamchanadam.github.io/agent-handoff-kit/agent-handoff-kit-ai-install.en.html and install or upgrade Agent Handoff Kit in this folder.

Required AI procedure

  1. Confirm the root first. Show the absolute folder path and ask: “Is this the folder where you want Agent Handoff Kit installed or upgraded?” If the user cannot confirm, stop with zero writes.
  2. Inspect before writing. Decide whether the folder needs a fresh install, a safe upgrade preview, a confirmed upgrade, a conflict stop, or only a health check.
  3. Protect user material. Exact artifact-identified Kit bytes may be updated. Non-exact, mixed, or unclear content must be preserved with a readable effective route, or the operation must stop safely.
  4. Use the appropriate command only after confirmation.
npx --yes @adamchanadam/agent-handoff-kit@latest init npx --yes @adamchanadam/agent-handoff-kit@latest upgrade --dry-run npx --yes @adamchanadam/agent-handoff-kit@latest upgrade --yes npx --yes @adamchanadam/agent-handoff-kit@latest doctor
Never “repair” by overwriting an unclear file. Do not delete local rules, do not use headings or language as ownership evidence, and do not turn a failed preview into a write.

What a successful upgrade means

One accepted state

The transaction, ordinary entry, doctor, report, and success message must read the same verified current-state witness.

Safe recovery

An interruption must leave either the complete old state or the complete new state. It must not leave a mixture that claims success.

Effective rules remain effective

After an upgrade, use the ordinary runtime entry to verify that preserved user rules are still reachable and active.

No false advice

If the accepted state already matches the running CLI, doctor must not tell the user to repeat the upgrade merely because retained metadata is older.

Required user-facing result

Do not reply only with terminal output or “done”. State the result in plain language:

Example: “✅ Upgrade completed. 📁 Folder: <absolute path>. 🩺 Doctor passed. Your preserved rules are still reachable. Next, return to the AI conversation and say Start Agent Handoff.”
  • If doctor fails, say what failed and stop; do not reinstall over the project.
  • If a conflict or ownership decision is unclear, preserve the bytes and explain that the operation stopped before writing.
  • If the AI is not already operating in the target folder, give the path-bearing startup sentence: Work in <folder>. Read AGENTS.md first, then Start Agent Handoff.
