# v0.3.20

## 本版新加了甚麼

本版把公開入口說明收斂成三條正式路徑：

```text
npx --yes @adamchanadam/agent-handoff-kit@latest init
npx --yes @adamchanadam/agent-handoff-kit@latest upgrade
npx --yes @adamchanadam/agent-handoff-kit@latest doctor
```

`upgrade --dry-run` 仍然保留，但只作升級前預覽；它不會寫入檔案，也不代表升級已完成。

介紹頁亦改為同時說明「開工」與「收工」：新對話用「開工」接回狀態，完成任務時用「收工」留下交接。

## 對你已有檔案的影響

升級會更新 README、CLI help、介紹頁文案與 release QA 守門。既有 AI 記憶文件、項目決策、交接紀錄與本地規則仍會保留。

## 建議下一步

新項目執行 `init`。已安裝舊版或已有 AI 記憶文件的項目，執行 `upgrade`。不確定狀態時，執行 `doctor` 檢查。
