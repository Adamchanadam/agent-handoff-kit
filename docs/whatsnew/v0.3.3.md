# v0.3.3

## 本版新加了甚麼

修正升級後的版本提示矛盾。完成 `upgrade` 後，`doctor` 不應再說項目版本落後於目前工具版本。若使用者從較舊版本直接升級到本版，工具也會提示這次跨度較大，並引導使用者查看 GitHub Release 的完整歷史說明。

## 對你已有檔案的影響

本版不會改動使用者填寫的項目內容。`upgrade` 後，`dev/PROJECT_INDEX.md` 內的「Agent Handoff Kit template version」資料列會更新為目前版本；其他由使用者填寫的資料列會保留。

## 建議下一步

執行 `doctor` 檢查項目健康即可。
