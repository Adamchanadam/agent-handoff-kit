# v0.4.6

## 本版新加了甚麼

- 每次都會讀的核心安全規則新增一句：AI 第一次執行新寫或改過的程式（包括測試和輔助腳本）前，即使確切指令來自你、文件或另一個 agent，也要先另外讀清楚它的用法，以及它會刪除或覆寫甚麼，再按 `dev/rules/coding.md` 第 6、7 條處理。
- 這樣不必等 AI 自行打開程式工作規則，也會在執行前看到這項要求。

## 對你已有檔案的影響

- 由 v0.4.5 升級時，本版的規則改動只在 `AGENTS.md` 內由工具管理的核心區段；核心區段以外的內容會保留，版本紀錄等照常更新。
- 如核心區段曾在本機被改動，升級會停手而不寫入檔案，可交給 AI 協助處理。
- 這是 AI 執行程式前的工作要求，用來減低誤刪風險；重要工作仍建議保持提交或備份。
- 本頁介紹 v0.4.6；可下載版本以 npm 發布記錄與 GitHub Release 為準。

## 建議下一步

升級後照常工作即可。若你給 AI 一條會執行新程式的指令，它可能先讀程式並說明風險，才決定是否照跑；這項規則本身不授權提交或備份。
