# v0.3.6

## 本版新加了甚麼

- `doctor` 新增交接生命週期一致性檢查：已完成或已驗證的事項，不應又以未解待辦、風險或下一次開工指令交給下一輪 AI。
- `dev/SESSION_HANDOFF.md` 的 `State Reconciliation Check` 新增一個欄位，要求 closeout 時明確確認完成／待辦／風險／開工訊息之間沒有矛盾，或已清楚重新分類。
- 發佈級 QA 新增反例驗收，覆蓋「`doctor` / `upgrade` 已完成，但 opening message 又要求下一輪重新調查」這類交接漂移。

## 對你已有檔案的影響

- 既有用戶內容應保留。
- 升級後，`dev/SESSION_HANDOFF.md` 會補上新的交接對賬欄位。
- 若舊 handoff 同時寫着某件事已完成、又把同一件事列為未解調查，`doctor` 會提示先修 handoff，不會把這種矛盾視為健康狀態。

## 建議下一步

- 已安裝舊版的專案，先執行 `npx @adamchanadam/agent-handoff-kit@latest upgrade --dry-run`。
- 預演結果沒有衝突後，再執行 `npx @adamchanadam/agent-handoff-kit@latest upgrade`。
- 升級後執行 `npx @adamchanadam/agent-handoff-kit@latest doctor`，確認交接狀態與下一步一致。
