# v0.3.27

## 本版新加了甚麼

這版新增「治理打通」。當你新建了 stock list、production guide、runbook、workflow、checklist、研究真源或其他重要文件，可以直接叫 AI 把它接入項目記憶。

你可以在 AI 對話中說：

```text
治理打通 docs/production-guide.md
```

英文也可以說：

```text
bridge governance for docs/production-guide.md
connect this document to governance
```

AI 會檢查文件本身是否說清楚角色與更新時機，`dev/PROJECT_INDEX.md` 是否登記它，`dev/DOC_SYNC_REGISTRY.md` 是否記下同步責任，相關 workflow 是否會提醒更新它，以及 handoff / log 是否各自放在正確角色。

## 對你已有檔案的影響

本版不會重寫你的項目內容，也不會自動刪除、改名、移動或合併文件。若升級時發現舊項目缺少治理打通路由或規則包段落，工具會在可安全判斷時補上；不能安全合併時會停手報衝突。

治理打通是按需要觸發的檢查，不會令每個普通文件都變成治理文件。repo-wide 掃描只列候選與缺口，讓 AI 和你判斷哪些文件真的需要接入長期記憶。

## 建議下一步

既有項目可直接升級：

```text
npx --yes @adamchanadam/agent-handoff-kit@latest upgrade
```

升級後照常在能讀寫本機資料夾的 AI 對話輸入 `Start Agent Handoff` 或「開工」。若新建了重要文件，可以直接說「治理打通 <檔案>」。若不確定 repo 內是否有漏接文件，可以說「掃描 repo 有沒有未接合文件」。
