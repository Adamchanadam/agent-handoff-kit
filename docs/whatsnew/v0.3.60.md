# v0.3.60

## 本版新加了甚麼

- 開工狀態卡要求 AI 用 fenced `text` block 顯示，保留 ASCII 間距；小貓圖案本身沒有更改。
- 普通文檔局部修改若目標文件本身就是權威來源，而且沒有碰到 Kit-managed 檔案、migration、release、closeout、外部副作用、跨真源衝突或阻塞風險，AI 應只做讀回與任務相關驗收。
- 這類普通文檔修改不應只因 Markdown 有改動就跑 `doctor`、寫 handoff / log，或重生 startup mirror。
- 發佈驗收加入比例化文檔修改情景矩陣，分開檢查普通目標文檔、新 durable document、Kit-managed 文件與開工卡顯示。

## 對你已有檔案的影響

這版不會自動改寫你的工作文檔。升級後，AI 在日常修 README、研究文件、草稿或其他普通目標文檔時，應少做不必要的 Kit 健康檢查與交接寫入。

如果任務真的修改 `AGENTS.md`、`dev/*`、rule packs、user-rules 見證、升級交易、正式收工或發佈流程，原有嚴格檢查仍然保留。

## 建議下一步

發布後在已安裝 Agent Handoff Kit 的項目執行 `upgrade --dry-run`，確認沒有 conflict，再執行 `upgrade --yes` 和 `doctor`。之後日常文檔修改照任務本身驗收；準備結束本輪工作時再說「收工」保存交接。
