# v0.3.53

## 本版新加了甚麼

- 升級與 `doctor` 不再把 Kit 管理範圍外的普通工作檔案、一般 Markdown 連結、inline path 或任意 RULE_PACKS row 當成檔案權威。
- `upgrade --dry-run` 與正式升級使用同一套完整預檢；正式寫入前會在 transaction lock 下重驗，漂移時不會替換目標檔，也不會假報成功。
- 舊版留下的 whole-root 或一般引用 witness，只有在不屬目前 typed Kit / USER_RULES / transaction / archive 範圍時才會安全退役；真正受保護的來源仍嚴格停手。
- 單純「開工」可從 `dev/PROJECT_INDEX.md` 唯一真實 Stack 版本列顯示已核實 Kit 版本；隱藏、重複、畸形或 prerelease 證據只顯示 `version unverified`。

## 對你已有檔案的影響

普通 docs、outputs、索引檔、一般連結或自訂說明不會再只因放在專案根目錄或被文字提到，就阻止升級或健康檢查。正式 Kit 檔案、交易紀錄、archive、已註冊 USER_RULES 與 runtime contract 仍會用嚴格路徑和 bytes 檢查保護。

## 建議下一步

如你的專案已安裝 Kit，請在專案資料夾告訴能操作本機檔案的 AI：「把 Agent Handoff Kit 升級到最新版，先預演並檢查，確認安全後再套用。」若只想繼續現有工作，說「開工」即可；版本證據不清楚時，AI 會顯示 `version unverified` 並停在狀態回報。
