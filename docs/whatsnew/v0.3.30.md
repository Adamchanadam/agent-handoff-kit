# v0.3.30

## 本版新加了甚麼

這版讓長任務中的新要求更不容易散落。當你在同一個任務中途陸續追加產品目標、開發清單、驗收規則、非目標或優先次序時，AI 會先把它們收斂成同一份目前任務契約，再繼續做事。

這樣下一個 AI 不需要靠聊天記憶猜測哪一段才是最新要求，也不會把同一件事分散寫進多份文件。

## 對你已有檔案的影響

本版不會刪除、改名、移動或合併你的文件。既有項目升級時，工具會保留既有 handoff、log、index、decisions、rule packs 與本地自訂內容。

如果你的項目已經有專門的規格、backlog、issue、runbook 或 README 作為任務真源，AI 應優先更新該真源，再在交接文件留下指向目前狀態的摘要。若沒有專門真源，才把目前任務契約合併到 `dev/SESSION_HANDOFF.md` 的當前狀態區。

本版也收窄了健康檢查與升級檢查通過後的提示：不是每完成一個小任務都要立刻完整收工；只有準備結束本輪工作、需要保存交接，或有下一輪必須知道的狀態時，才輸入「收工」。

## 建議下一步

已安裝舊版的項目可升級：

```text
npx --yes @adamchanadam/agent-handoff-kit@latest upgrade
```

升級後照常在能讀寫本機資料夾的 AI 對話輸入 `Start Agent Handoff` 或「開工」。
