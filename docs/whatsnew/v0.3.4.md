# v0.3.4

## 本版新加咗咩

本版修補升級後版本敘事不一致的問題。既有專案執行 `upgrade` 後，`dev/PROJECT_INDEX.md` 內的「Agent Handoff Kit template version」資料列會在合併完成後再更新為目前 CLI 版本，避免先更新、後又被舊合併結果覆蓋。

升級工具也會辨認「只有版本資料列過期」的情況。即使沒有新增檔案、沒有合併檔案、沒有衝突，只要這一列仍是舊版本，就不會誤報「已經是最新版本，沒有檔案需要建立或合併」。

## 對你已有檔案嘅影響

本版只會更新 `dev/PROJECT_INDEX.md` 的 template version metadata。這一列屬工具維護的模板資料，不是你填寫的項目內容。你在 External Sources、Fact Base、Workspace Identity 等表格中填過的內容仍會保留。

升級紀錄也新增 metadata section，會寫明這次是否更新了版本資料列，方便日後追溯。

## 建議下一步

執行 `upgrade` 後再執行 `doctor`。若 `doctor` 顯示 `status: passed`，並且項目狀態速覽不再提示 root 落後 CLI，即代表這次熱修已生效。
