# v0.3.55

## 本版新加了甚麼

- 單獨 `Start Agent Handoff` /「開工」若需要更新對話標題，會先完成 startup card 的目前目標與推薦下一步推導，再在顯示 card 前套用標題。
- 標題的主要動作依序取同一句明確任務、已載入目前目標、推薦下一步；generic continuity trigger 不再被誤當成標題內容。
- 沒有具體項目名稱與具體主動作時，工具會跳過改名，避免把「開工」這類泛用入口寫成看似有任務意義的標題。

## 對你已有檔案的影響

這版不新增 runtime 文件、命令、schema 或治理機制。已安裝項目的交接檔、規則包、交易 journal、PROJECT_INDEX 與 USER_RULES contract 都沿用既有升級邊界。影響只限支援安全 title readback/control 的 AI runtime 在明示 continuity startup 時，使用更晚、更具體的已載入事實來命名對話。

標題仍是 display-only：不是任務授權、進度、完成證據、健康結果或新的真源；不支援標題控制的平台會照舊靜默略過。

## 建議下一步

如果你只是日常使用，發布後照常在項目資料夾對 AI 說 `Start Agent Handoff` 或「開工」。若你的平台支援對話標題控制，標題會更穩定地反映實際項目與下一步；若沒有支援，使用方式不變。
