# v0.3.61

## 本版新加了甚麼

- 收工流程現在明確要求 write-minimal：只更新真實狀態有變的 handoff 欄位或段落。
- 已是最新的 `dev/SESSION_HANDOFF.md` 內容不需要為了「確認過」而全段重寫。
- `START_NEXT_SESSION_PROMPT.txt` 會先讀回比對；只有與 handoff 開工訊息不一致時才重生。
- 發佈驗收加入新斷言，防止收工流程退回無條件重生 mirror 或全段確認。

## 對你已有檔案的影響

升級不會自動改寫你的工作內容。之後 AI 做正式收工時，仍會保存必要交接、log、索引與 closeout-status 證據，但應少做不必要的全段重寫和便利副本重生。

如果 handoff 內容真的改了、startup prompt 落後、closeout-status 失敗，或項目規則要求額外持久化，原有嚴格檢查仍然保留。

## 建議下一步

發布後在已安裝 Agent Handoff Kit 的項目執行 `upgrade --dry-run`，確認沒有 conflict，再執行 `upgrade --yes` 和 `doctor`。日常工作按任務本身驗收；準備結束本輪工作時再說「收工」保存交接。
