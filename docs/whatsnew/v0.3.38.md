# v0.3.38

## 本版新加了甚麼

這版修補舊項目升級時的收工流程補丁。

v0.3.37 已把外部工具資源收口檢查放入完整收工流程；v0.3.38 進一步確保舊項目升級後，`AGENTS.md` 也一定補上這條核心收工規則。

## 對你已有檔案的影響

升級會檢查你的 `AGENTS.md` 是否已包含外部工具資源收口檢查。若缺少，工具會用既有安全合併機制補回；若你的本地檔案有無法安全判斷的自訂衝突，仍會停下並要求人工處理。

它不會自動 kill 不明 process、刪除共享 cache、停用 MCP / plugin、修改 browser profile，亦不會改你的外部工具配置。

## 建議下一步

已安裝舊版的項目可升級：

```text
npx --yes @adamchanadam/agent-handoff-kit@latest upgrade
```

升級後可執行：

```text
npx --yes @adamchanadam/agent-handoff-kit@latest doctor
```

若你之前已升到 v0.3.37，也建議再升級一次，確保舊項目的 `AGENTS.md` 已補上完整收工資源檢查。
