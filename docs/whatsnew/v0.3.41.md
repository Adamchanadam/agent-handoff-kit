# v0.3.41

狀態：正式發佈版本。

## 本版新加了甚麼

- 升級器會辨識所有 54 個 npm 正式版本實際安裝過的 Kit 檔案，不再逐個檔案等用戶報錯後補例外。
- 歷史基線以 npm 正式發佈物為準；即使同版 Git tag 內容不同，也不會拿錯來源判斷升級。
- CLI 會分開顯示實際項目版本、目標版本及目前交易；舊 stage 或已回滾報告不再容易被誤當現況。
- 中斷恢復會核對目標、stage、backup、路徑與雜湊；資料不完整、內容已另改或路徑不安全時保留 lock 並停手，不會假稱已回滾。

## 對你已有檔案的影響

未修改的 Kit 舊檔會自動更新。清楚分隔的本地規則附錄會保留；改寫官方規則或來源矛盾時仍會零寫入停手，不會用整檔覆寫換取綠燈。不存在的安裝資料夾亦只會在確認後建立，取消不留空資料夾。

## 建議下一步

舊專案可照常執行 `upgrade`；一般使用者毋須閱讀 `safety.md` 或其他治理檔來決定怎樣合併。
