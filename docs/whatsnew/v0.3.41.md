# v0.3.41

狀態：修正候選，尚未正式發佈。

## 本版新加了甚麼

- 升級器會辨識所有 54 個 npm 正式版本實際安裝過的 Kit 檔案，不再逐個檔案等用戶報錯後補例外。
- 歷史基線以 npm 正式發佈物為準；即使同版 Git tag 內容不同，也不會拿錯來源判斷升級。
- CLI 會分開顯示實際項目版本、目標版本及目前交易；舊 stage 或已回滾報告不再容易被誤當現況。

## 對你已有檔案的影響

未修改的 Kit 舊檔會自動更新。清楚分隔的本地規則附錄會保留；改寫官方規則或來源矛盾時仍會零寫入停手，不會用整檔覆寫換取綠燈。

## 建議下一步

候選通過全面檢及正式發佈後，舊專案可照常執行 `upgrade`；一般使用者毋須閱讀 `safety.md` 或其他治理檔來決定怎樣合併。
