# v0.3.34

## 本版新加了甚麼

這版修補公開教學提示在 WhatsApp 轉發時的 URL 邊界問題。

可複製提示句現在是：

```text
請讀取 https://adamchanadam.github.io/agent-handoff-kit/agent-handoff-kit-ai-install.html ，並在這個資料夾安裝或升級 Agent Handoff Kit。
```

`agent-handoff-kit-ai-install.html` 後面先加一個空格，再接中文逗號，避免訊息軟件把逗號連到 URL 裏。

## 對你已有檔案的影響

本版不會刪除、改名、移動或自動合併你的文件。runtime 行為與 v0.3.33 相容，主要改動是 README、GitHub Pages 教學頁與 release QA 的提示文字。

## 建議下一步

已安裝舊版的項目可升級：

```text
npx --yes @adamchanadam/agent-handoff-kit@latest upgrade
```

如果你只是把安裝提示轉發給 AI，請使用本頁上方的新提示句。
