# v0.3.22

## 本版新加了甚麼

升級更穩。舊項目升級時，如果只是 Kit 自己的維護文字被正常 AI 使用改散、刪走或放錯位置，`upgrade` 會盡量在可信結構內非破壞性補回，並在升級後讓 `doctor` 通過。

同時，工具不會因為檔尾或錯誤位置出現某段文字就當作有效。這避免了「表面有字、實際結構壞了」的假性通過。

## 對你已有檔案的影響

你的任務內容、本地規則、紀錄與資料列會保留。升級只會處理 Kit 自己能辨認的維護結構；遇到安全規則被改成不可判斷的語義、管理區重名，或找不到可信插入位置時，工具會停手並列出衝突，不會自行覆寫。

## 建議下一步

既有項目可直接升級：

```text
npx --yes @adamchanadam/agent-handoff-kit@latest upgrade
```

升級完成後可執行：

```text
npx --yes @adamchanadam/agent-handoff-kit@latest doctor
```

若看到 conflict，請把輸出交給能讀寫該專案資料夾的 AI agent，要求它按非破壞方式審視衝突位置。
