# v0.3.40

狀態：未發布候選。

## 本版新加了甚麼

- 修正 v0.3.39 對大型交接內容的生命週期誤判，以及對舊 `SESSION_LOG` 多筆歷史標記的錯誤衝突。
- 升級器只更新現行日誌範本，保留歷史 entry；真正完成／待辦矛盾、空白追蹤條件及模糊範本仍會停止。
- 支援精確相符的 v0.3.38 continuity quick-fix 規則包安全收斂到現行官方版本；有額外本地修改時仍保守停手。

## 對你已有檔案的影響

既有大型繁中專案及保留多筆歷史日誌的專案，不需要刪改歷史內容來迎合升級器。升級仍會先預演、備份及驗收；不能安全判斷時不會覆寫。

## 建議下一步

目前仍未發布。發布後，v0.3.38 或 v0.3.39 專案可使用正常 `upgrade` 路徑；毋須手動合併日誌標記或大幅改寫交接內容。
