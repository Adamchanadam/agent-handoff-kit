# v0.3.67

## 本版新加了甚麼

- 說「開工」後，Kit 會先在最少必要的交接資料中找出專案與當前要做的事，再安全地把新 thread 命名成「專案｜當前行動」。這只改畫面標題，不會改你的任務、權限或交接內容。
- 收工檢查現在會分辨「已完成」和「仍有限制／待跟進」是否在說同一件事，減少把誠實記錄的限制誤判為互相矛盾。
- 升級時更小心保留你寫在下一次開工提示中的內容；只會更新能精確證明屬於舊官方範本的完整開場，或在不刪除你補充內容下補回遺失的官方安全指令。

## 對你已有檔案的影響

- 不需要手動改名或重寫交接檔。已有清楚名稱、用戶自己設定的名稱及不適合推斷專案名稱的情況，Kit 會保留或跳過。
- 你原有的收工記錄可以如實保留「本地完成、外部驗收仍有限制」等不同範圍；真正針對同一範圍的完成與未完成矛盾，仍會被擋下。
- 升級仍先預演；遇到未知的本地改動或衝突，Kit 會停止並要求你決定，不會用空白範本覆寫內容。

## 建議下一步
