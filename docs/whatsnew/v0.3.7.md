# v0.3.7

## 本版新加了甚麼

修正舊項目執行 `doctor` 時容易誤會的 `npx` 路徑說明。官方示範統一改用 `npx --yes @adamchanadam/agent-handoff-kit@latest ...`，讓 npm 先取得執行工具的提示不再被誤解成 `doctor` 正在安裝或修改項目。

## 對你已有檔案的影響

本版不改動已安裝項目的交接文件結構。`doctor` 仍只做檢查，不會建立或修改項目文件。README、CLI help、新手介紹頁與操作指南會更清楚分開兩件事：項目內的 Kit 文件，以及電腦用來執行命令的 npm 工具。

## 建議下一步

日常檢查請使用：

```bash
npx --yes @adamchanadam/agent-handoff-kit@latest doctor
```

如你已經有舊版 Kit 文件，先跑 `upgrade --dry-run` 預覽，再決定是否正式升級。
