# v0.3.37

## 本版新加了甚麼

這版把外部工具資源收口檢查正式放入完整收工流程。

如果 AI 本輪使用過 MCP、browser、自動化工具、notebook、crawler、DevTools、Playwright、本地 helper service 或由任務啟動的 helper process，收工時必須檢查資源是否已安全收口。

AI 可以自動關閉或清理能證明屬於本任務的資源；不明、共享、使用者、系統或其他 AI agent 可能擁有的資源，只能先列證據與建議處理方法，不能直接終止或刪除。

## 對你已有檔案的影響

升級會更新 Agent Handoff Kit 的 runtime closeout 規則與檢查錨點。

它不會自動 kill 不明 process、刪除共享 cache、停用 MCP / plugin、修改 browser profile，亦不會改你的外部工具配置。真正能自動處理的，只限可證明屬於本任務或 agent-managed 的有界資源。

## 建議下一步

已安裝舊版的項目可升級：

```text
npx --yes @adamchanadam/agent-handoff-kit@latest upgrade
```

升級後可執行：

```text
npx --yes @adamchanadam/agent-handoff-kit@latest doctor
```

日後當你要求 AI「收工」時，若該輪曾使用外部工具，收工結果應包含外部工具資源收口狀態。
