# v0.4.8

## 本版新加了甚麼

- 收工卡多了一行「📦 Footprint」，顯示專案資料夾約有多大、有多少個檔，以及最大的三個資料夾。專案突然變大時，收工時就看得到。
  - 只讀資料夾及檔案的大小資料，不讀檔案內容，也不寫入任何東西。
  - 最多量約 4 秒；時限內量不完，會顯示「observed at least」（至少有這麼多）；如果量度程式本身逾時或出錯，會顯示「unavailable」。
  - 只供參考：收工是否完成，與這一行無關。
  - 會跳過捷徑連結，以及掛載在專案內的其他磁碟或網絡資料夾。
  - 在不准開啟輔助程式的環境（例如 Codex 沙盒），會顯示「unavailable (helper process not permitted)」。
- AI 規則新增一條：測試、fixture 及輔助腳本產生的臨時檔（例如瀏覽器設定檔、快取、快照、臨時副本），要放在該工具自己的暫存位置，不可放進證據或交付資料夾，成功後要刪除。收工時，凡跑過工具、測試或腳本，AI 都要檢查有沒有留下這類臨時檔。這條規則不給 AI 新的刪除權限。

## 對你已有檔案的影響

- 由 v0.4.7 升級時，只更新 `dev/rules/coding.md` 及 `dev/rules/closeout.md` 的官方內容；規則包內你自己加的部分會保留，`AGENTS.md` 核心不變。
- 足跡行只走訪專案資料夾之內的內容，並跳過捷徑連結及其他磁碟的掛載資料夾，所以放在專案外的臨時檔一般不會計入。少數情況下，以掛載方式接入同一磁碟的資料夾仍會被計算。
- 本頁介紹 v0.4.8；可下載版本以 npm 發布記錄與 GitHub Release 為準。

## 建議下一步

升級後照常工作即可。如果收工卡顯示專案比預期大，可以請 AI 找出佔空間的資料夾，再決定要不要清理；Kit 不會自動刪除任何檔案。
