# v0.3.18

## 本版新加了甚麼

本版把 Agent Handoff Kit 的適用邊界講清楚：它是給能讀寫本機專案資料夾的 agentic AI 長任務使用，不是給普通 web chat AI 使用。

README、CLI 安裝後輸出、介紹頁與操作指南會改用同一條固定開工句：AI 先讀 `AGENTS.md`，再打開 `START_NEXT_SESSION_PROMPT.txt`，按檔案內的真正開工內容接力。

若 AI 已在正確專案內，也可以用 `Start Agent Handoff` /「開工」開始接力，用 `Wrap up Agent Handoff` /「收工」保存交接。若你說的是「某某開工 / 某某收工」這類可能有其他意思的話，AI 會先問清楚是否指 Agent Handoff Kit。

## 對你已有檔案的影響

升級會更新公開說明、CLI 輸出、runtime closeout 規則與初始 `START_NEXT_SESSION_PROMPT.txt` 模板。既有用戶內容仍保留；收工後的真正交接內容仍由 `dev/SESSION_HANDOFF.md` 生成。

普通 web chat AI 若不能讀寫本機資料夾，不屬於支援場景。上載檔案或貼上交接內容不能取代本工具需要的本機讀寫能力。

## 建議下一步

若你使用 Claude Code、OpenAI Codex、Gemini CLI、Google Antigravity 或其他能讀寫本機專案資料夾的 AI agent，日常開工使用固定句即可：

```text
Work in <你的專案資料夾>. Read AGENTS.md first. Then open START_NEXT_SESSION_PROMPT.txt and follow the opening message inside. If START_NEXT_SESSION_PROMPT.txt is missing or seems stale, read dev/SESSION_HANDOFF.md instead. Before changing anything, tell me the current state and your recommended next step.
```

完成任務時仍然只要對 AI 說「收工」，讓它更新交接文件與 `START_NEXT_SESSION_PROMPT.txt`。
