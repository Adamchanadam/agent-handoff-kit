# v0.3.32

## 本版新加了甚麼

這版修補兩個真實使用中暴露的交接問題：AI 明明看到「收工」，卻只回一段普通總結；以及 AI 工作中生成 Markdown 文件後，沒有入庫、同步、合併或標成臨時證據，令文件變成孤兒。

升級後，清楚的收工語句會要求 AI 進入完整 Agent Handoff Kit closeout，而不是只在聊天中口頭總結。`doctor` 也會檢查常見生成文件位置，若發現未登記的 generated Markdown / durable artifact，會指出路徑並要求補登記、合併或分類。

## 對你已有檔案的影響

本版不會刪除、改名、移動或自動合併你的文件。既有項目升級時，工具會保留 handoff、log、index、decisions、rule packs 與本地自訂內容。

如果你的項目已有 `outputs/`、`docs/` 或其他位置的 generated Markdown，升級後 `doctor` 可能提示它們需要登記到 `dev/PROJECT_INDEX.md`、加入同步登記、合併回既有真源，或標成 draft / temporary / one-time evidence。這是為了讓下一個 AI 分得清哪些文件是正式依據，哪些只是一次性證據。

## 建議下一步

已安裝舊版的項目可升級：

```text
npx --yes @adamchanadam/agent-handoff-kit@latest upgrade
```

升級後執行 `doctor`。若提示有 orphan generated Markdown，請讓能讀寫本機資料夾的 AI 先整理入庫或分類，再繼續工作。
