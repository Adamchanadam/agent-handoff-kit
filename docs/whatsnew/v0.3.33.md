# v0.3.33

## 本版新加了甚麼

這版修補 AI 使用外部工具時容易盲猜的問題。當任務涉及 Notion、Google Drive、Obsidian、GitHub、Connector、MCP、CLI、API、URI 或 plugin API，AI 不應只靠舊知識或舊例子推斷工具名、參數、endpoint 或指令。

升級後，AI 在首次使用外部工具、寫入、不可逆操作、API / SDK / CLI / URI / plugin API、或工具錯誤後重試前，要先核對目前 runtime 暴露的 tool schema、官方文件、官方型別 / sample，或有版本日期的本地 runbook。不能核實時，AI 應標示 blocked / unverified，或改交人工處理包，不應連續試錯。

## 對你已有檔案的影響

本版不會刪除、改名、移動或自動合併你的文件。既有項目升級時，工具會保留 handoff、log、index、decisions、rule packs 與本地自訂內容。

如果你的 `dev/PROJECT_INDEX.md` 仍使用舊欄位 `Credential Location`，升級會以非破壞方式改成 `Credential Reference（no value）`。這只是把「記錄機密位置」改清楚為「只記安全儲存參考，不記 value」；既有整合記錄會保留。

## 建議下一步

已安裝舊版的項目可升級：

```text
npx --yes @adamchanadam/agent-handoff-kit@latest upgrade
```

升級後執行 `doctor`。若你的項目會用 Notion、Google Drive、GitHub、Obsidian 或其他外部工具，請在開工時讓 AI 先讀 `dev/PROJECT_INDEX.md` 的整合聲明，再按目前工具 schema 或官方文件執行。
