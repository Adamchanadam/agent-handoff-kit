# v0.3.42

## 本版新加了甚麼

- 升級時，Kit 內容只會在來源身分、目標位置與原始 bytes 全部精確吻合時替換。
- 原檔混有你或其他 AI 加入的規則時，工具不會因標題、語言或位置猜它屬於誰；無法精確確認的內容會整份保留，並由正式讀取入口核對仍然有效。
- 升級意外中斷時，之後只可看到完整的舊狀態或完整的新狀態。`doctor`、升級報告和成功提示會讀同一個當前狀態，避免一邊說成功、另一邊其實讀不到規則。

## 對你已有檔案的影響

這個候選特別保護已有自訂規則的專案：原始 bytes 會被核對，讀取路徑與規則效力亦會被重讀。若工具無法證明安全效果，會保留舊狀態或停手，而不是為了完成升級覆寫內容。

## 建議下一步

如你已有 Agent Handoff Kit，請讓能讀寫專案資料夾的 AI 先執行 `upgrade`，再執行 `doctor`。升級前如有重要自訂規則，保留原專案備份會更安心。
