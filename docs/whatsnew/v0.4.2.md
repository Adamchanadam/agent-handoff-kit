# v0.4.2

## 本版新加了甚麼

- 長工作遇到跨步驟或反覆沒有進展的問題時，AI 會回到原因和安全界線重新核對，不把重複嘗試當成完成。
- 開工遇到未完成的升級會先停下來，避免讀到更新到一半的交接資料。
- 收工時會核對必須處理的工作紀錄和專案快捷入口；有缺口便清楚列作阻礙，不以看似完成的狀態卡掩蓋。具體待辦可以如實標示尚待核實的資料，不會只因這些字眼而被誤擋。
- 發布前後的驗收會分開本機演練與正式更新，並保留每個快捷入口的操作證據，避免未證明的結果被說成已可用功能。

## 對你已有檔案的影響

- 這些調整不會自動改寫你已保存的交接、工作紀錄或自訂內容。
- 需要停下來檢查時，AI 應說明仍欠甚麼，而不是把未完成的檢查當成成功。
- 本頁介紹 v0.4.2；可下載版本以 npm 發布記錄與 GitHub Release 為準。

## 建議下一步

繼續用 Session 接力棒保存工作脈絡。需要更新時，請 AI 先檢查目前可安全使用的正式版本，再在你的專案內處理。
