# v0.3.36

## 本版新加了甚麼

這版新增更穩定的「推薦下一步」交接契約。

AI 開工或完成治理類任務時，不應只列一堆待辦，也不應把已經判斷好的技術方向變成開放式反問。它需要直接說出建議下一步，並附上一句原因。只有真正需要你作取捨時，才列出選項。

這版亦把治理打通流程合併回既有 `agent-governance` 規則包。公眾版不新增另一個 governance-bridge skill，避免同一套治理規則分裂成多個真源。

## 對你已有檔案的影響

升級會更新 Agent Handoff Kit 的 runtime 模板、communication 規則包、agent-governance 規則包與檢查錨點。

既有 `dev/SESSION_HANDOFF.md` 會以非破壞方式補上 recommended-next-step 欄位與對賬要求。若你已有本地 handoff 內容，升級會保留；遇到無法安全合併的結構才會停手並要求人工處理。

## 建議下一步

已安裝舊版的項目可升級：

```text
npx --yes @adamchanadam/agent-handoff-kit@latest upgrade
```

升級後可執行：

```text
npx --yes @adamchanadam/agent-handoff-kit@latest doctor
```

若你正在整理治理文件、規則包、runbook 或長期操作流程，請讓 AI 使用現有 `agent-governance` 規則包完成接合，不要另外建立一套平行治理入口。
