# v0.3.21

## 本版新加了甚麼

收工流程更輕。AI 每次收工仍會保存交接與檢查必要狀態，但長期整理不再每次完整執行；它會先做短觸發檢查，命中條件時才整理舊紀錄或長期決策。

## 對你已有檔案的影響

既有交接文件與紀錄會保留。升級後，`dev/SESSION_LOG.md` 與 `dev/PROJECT_DECISIONS.md` 的維護規則會改為：N≥11、主檔過長、決策累積、任務方向改變、架構取捨、跨 session 模式，或每十次收工兜底時才完整整理。

## 建議下一步

既有項目可直接升級：

```text
npx --yes @adamchanadam/agent-handoff-kit@latest upgrade
```

升級後照常對 AI 說「收工」即可；你不需要手動整理紀錄。
