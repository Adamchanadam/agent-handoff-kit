# v0.4.7

## 本版新加了甚麼

- 每次都會讀的核心安全規則加了三句：
  - AI 不可執行 `rm -rf`、`Remove-Item -Recurse -Force` 等指名禁用的刪除指令，要改用較窄、可還原的做法，或交你手動處理；
  - 不可終止或清理不能證明屬本任務的程式、快取或瀏覽器設定，除非你確認確切目標；
  - 不可叫你貼出密碼或金鑰，也不可把它們寫入專案檔。

  這些規則本來已在 `dev/rules/safety.md`，現在 AI 不必打開規則包也會看到。
- 如專案根目錄的 `AGENTS.md` 太長（超過 32,768 bytes），健康檢查會提醒你：Codex 預設只讀首 32,768 bytes，並告訴你哪些部分會讀不到、怎樣處理。

## 對你已有檔案的影響

- 由 v0.4.6 升級時，本版的規則改動只在 `AGENTS.md` 內由工具管理的核心區段；核心以外的內容會保留。
- 如核心區段曾在本機被改動，升級會停手而不寫入檔案，可交給 AI 協助處理。
- 大小提醒只供參考，不會令健康檢查失敗。
- 本頁介紹 v0.4.7；可下載版本以 npm 發布記錄與 GitHub Release 為準。

## 建議下一步

升級後照常工作即可。如果你用 Codex，而健康檢查顯示大小提醒，可在個人 Codex 設定 `~/.codex/config.toml` 加入一行 `project_doc_max_bytes = 65536`；設定一次，所有專案都適用。用 Claude Code 不需要這一步。
