# v0.3.35

## 本版新加了甚麼

這版新增外部工具資源生命週期治理。

當 AI 使用 MCP、browser、plugin、Chrome、Notion、NotebookLM、Firecrawl、Playwright、Context7，或由它們啟動的 `node.exe` / `python` helper 後，任務收尾要檢查是否有不必要的工具資源殘留。

規則重點是 ownership：AI 只可自動處理能證明屬於本任務的資源；若資源可能屬於使用者、系統、其他 AI agent，或 ownership 未明，只能回報程序名稱、數量、資源影響與建議，不得未經確認自行終止或清理。

## 對你已有檔案的影響

升級會更新 Agent Handoff Kit 的 runtime 規則與檢查錨點。它不會自動 kill process、刪 cache、停用 MCP / plugin、修改 browser profile，亦不會改你的外部工具配置。

如果你已有自訂治理文字，升級會盡量合併；遇到衝突時會停下並要求人工處理。

## 建議下一步

已安裝舊版的項目可升級：

```text
npx --yes @adamchanadam/agent-handoff-kit@latest upgrade
```

升級後可執行：

```text
npx --yes @adamchanadam/agent-handoff-kit@latest doctor
```

若你正遇到 MCP / browser / node helper 殘留問題，請讓 AI 先做 ownership-based 資源檢查；未確認屬於本任務的程序或 cache，不應直接清理。
