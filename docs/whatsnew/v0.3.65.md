# v0.3.65

## 本版新加了甚麼

- 修正部分舊安裝升級後版本號已更新、必要規則卻仍然過時的問題，也修正工作日誌標記造成的誤判。
- 交接會寫清整體目標、目前子任務、從哪裡接續、還欠哪些驗收，以及資料讀到哪裡、哪些仍未核實。
- 收工前，AI 要只憑交接內容重建下一步，再對照原始要求及成果。收工卡檢查保存狀態與已記錄的檢查；它不會自動證明任務結論正確。

## 對你已有檔案的影響

升級保留原有工作內容及交接紀錄。可辨識的官方舊規則會更新，自訂內容在可安全合併時保留；無法判斷的修改仍會停止，讓 AI 先查清楚。下一次正式收工時，AI 才按新規則核對實際工作狀態，不在升級時猜補。

工作仍未完成或受阻，也可以清楚交接；要保留原因、影響及續接條件。「已保存」不代表整體任務完成。簡單任務只記必要資訊。

## 建議下一步

升級時，在原有專案內請 AI 讀取安裝頁並升級 Agent Handoff Kit；之後照常說「開工」、交代任務，結束時說「收工」。不需要學習新的指令或手動整理交接欄位。
