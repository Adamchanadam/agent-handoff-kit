# v0.3.9

## 本版新加了甚麼

修正交接狀態檢查的一個誤判：如果 handoff 已明確寫出「已解決」，但同一句同時提到仍有下一步要做，`doctor` 不應把它當成未完成。

## 對你已有檔案的影響

本版不會覆寫你的 handoff 內容。它只令 `doctor` 更準確：真正未收口的交接仍會被指出；已明確收口但保留後續待辦的文字，不應再被誤殺。

## 建議下一步

升級後照常執行：

```bash
npx --yes @adamchanadam/agent-handoff-kit@latest doctor
```

如果 `doctor` 通過，就可以繼續日常使用。如果它指出 handoff 需要修補，請把輸出貼給 AI，先修交接狀態，不要重裝覆蓋項目文件。
