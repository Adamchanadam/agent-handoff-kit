# v0.3.43

## 本版新加了甚麼

- 升級已完成並通過驗證後，`doctor` 會清楚顯示已接受的目前狀態，不會因保留的舊資料欄位而叫你再升級一次。

## 對你已有檔案的影響

本版不會為了更新版本提示而改寫你保留的舊資料或自訂規則。原有的完整位元組保護、正式讀取入口和交易恢復機制維持不變。

## 建議下一步

如你剛升級完成，執行 `doctor` 應直接反映目前已接受的狀態。只有工具真的較舊、項目仍未升級，或 npm 有新版時，才按提示處理。
