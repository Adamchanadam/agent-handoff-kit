# v0.3.50

## 本版新加了甚麼

- 正式 QA runner 改為有界 async 執行，避免 timeout 後子程序不退出時整個 gate 無限等待。
- timeout、子程序 signal、spawn / transport error、partial PASS 和 wrapper false-green 會被分開記錄，不再以外層成功冒充內層成功。
- Windows `npm.cmd` / `npx.cmd` fallback 的 shell option 會正確傳入 async runner。
- closeout 改為差量重試：身份未變時不重跑已完成 task QA，只從第一個未完成或未確定 gate 繼續。
- WORK closeout checker 補上高輸出 pipe-drain self-test，避免大量 stdout / stderr 造成假逾時。

## 對你已有檔案的影響

這是維護者側 closeout / QA runner 穩定性修補。一般使用者的專案內容不會因此被自動改寫；既有 closeout、upgrade、doctor 邊界仍維持保守。

## 建議下一步

維護者發布前必須先完成正式 full gate、獨立 review receipt、push / tag / npm / GitHub Release 授權與 postpublish readback。一般使用者只需繼續使用 `@latest`；若遇到 closeout 或 upgrade blocked，保留輸出並交給能讀寫該資料夾的 AI 判斷。
