# v0.3.46

## 本版新加了甚麼

- `handoff blocked` 現在會直接說明：這不是失敗；只是還有事未保存、未提交、未驗證或需要處理。
- 收工規則要求 AI 保留這段人話說明，不可把 blocked 說成已完成交接。
- README 與英文 README 加入貓貓狀態圖例，讓 npm 內附說明與 GitHub Pages 入門頁一致。
- 發佈檢查新增 blocked card 回歸保護，防止日後安裝後提示又退回只有技術字句。

## 對你已有檔案的影響

本版不會主動改寫你既有專案的 handoff、規則或工作文件。更新後，新安裝或升級的 Kit 會帶入新的收工規則；執行 `closeout-status` 時，blocked 卡會顯示更清楚的人話下一步。

## 建議下一步

若你在收工時看到 `( x.x ) handoff blocked`，不要把它當成壞了，也不要當作已完成交接。先照 Blocker 行處理，完成保存、提交、驗證或其他待辦後，再重新收工。
