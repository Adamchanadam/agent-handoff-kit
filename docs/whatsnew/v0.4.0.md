# v0.4.0

## 本版新加了甚麼

- 八個 `handoff-kit-` 快捷入口，集中處理開工、收工、進度頁、文件對齊、新手引導、保存工作規則、檢查及功能選單。只安裝在指定專案，拒絕全域位置。
- 新增繁中／英文動態 Dashboard，把目前工作、未完成事項、歷程及文件關係放在同一頁。AI 正常保存紀錄後，畫面自動更新；不用另外寫進度報告，查看與更新畫面不呼叫 AI。
- 修正開工可能只讀部分交接包卻聲稱已恢復的缺口：須讀齊同一版本並核對工作脈絡；截斷時分段補讀，未完成便如實顯示。

## 對你已有檔案的影響

- 升級先預演，保留你的專案資料；遇到未知改動或衝突便停止，不用空白範本覆蓋。
- 快捷入口須另外啟用；不會安裝到全域，也不覆寫已有不同內容的同名入口。Codex 使用技能選單或 `$handoff-kit-progress`；其他支援的工具使用對應快捷入口。
- Dashboard 沿用 Node.js 與瀏覽器。沒有工作表的舊專案仍可讀已有交接內容，不會替你猜造進度；長期歷史按索引及日期分批讀取。

## 建議下一步

請 AI 在你的專案資料夾處理：

> 為這個專案升級 Agent Handoff Kit，先預演並保留現有資料；完成後啟用專案快捷入口及開啟 Dashboard。
