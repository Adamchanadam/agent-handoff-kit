# v0.4.1

## 本版新加了甚麼

- 新增 `handoff-kit-update`。你主動要求時，AI 會先檢查 npm 的正式版本；有新版才按既有安全流程為這個專案更新，已是最新版便不改檔。
- 所有專案快捷入口會隨正常安裝或升級一併交付。舊官方入口只有在內容完全符合時才會安全更新；自訂內容或衝突會保留，並先向你說明。
- `handoff-kit-progress` 會隨正常安裝或升級帶入本機進度頁程式。之後開啟進度頁不必每次下載 npm，暫時無法連線或快取不可寫時仍可查看已保存的專案狀態。
- 整理入門、指南、安裝及案例頁，讓常用指令、交接用途和安全界線更容易閱讀，並沿用現有品牌視覺。

## 對你已有檔案的影響

- 新入口只安裝在你指定的專案，不會寫入電腦的共用 AI 設定位置。
- 更新會保留現有專案資料。遇到自訂內容、衝突或無法確認的版本，AI 會停下來說明，不會直接覆寫或降回舊版。
- 已安裝或完成升級的專案，可直接用進度頁查看已保存的內容；這不會代替交接讀取，也不會把未保存的工作當成完成。
- 本頁介紹 v0.4.1；可下載版本以 npm 發布記錄與 GitHub Release 為準。

## 建議下一步

先看完整指南了解各個指令的用途；如想使用最新正式版，請在專案的 AI 對話輸入「檢查更新」或 `handoff-kit-update`，讓 AI 先確認是否有可安全更新的版本。
