# v0.3.49

## 本版新加了甚麼

- Conflict 下一步改為更清楚的產品路徑：用戶不用判斷技術差異，也不用重裝或整檔覆寫。
- 遇到未知或自訂本地內容時，交由能讀寫該專案的 AI 在用戶授權下做語意合併。
- 未知本地 hash 只作內容 witness，不代表 Kit 可以理解或覆寫。
- 合併後由 `upgrade --dry-run`、`doctor` 與 hash / readback 驗收。
- 發佈前 QC 加入守門，避免再把一般用戶或維護者收納用戶本地內容當成 conflict 解法。

## 對你已有檔案的影響

本版主要改 CLI 與 AI 安裝頁的 conflict 指引，不會放寬自動覆寫規則。真正自訂或來源不明的內容仍會保守停手；AI 需要先取得用戶授權，再做合併。

## 建議下一步

升級前仍先跑 `upgrade --dry-run`。若有 conflict，把 CLI 輸出交給能讀寫該資料夾的 AI，請它在你授權下合併；合併後再跑 `upgrade --dry-run`、`doctor`，並核對 hash / readback。
