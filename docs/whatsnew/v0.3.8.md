# v0.3.8

## 本版新加了甚麼

修正舊項目升級時的狀態提示：如果 Kit 檔案已是最新版，但交接文件仍有待核對的 closeout 欄位，`upgrade` 不再說可以繼續日常使用，而會提示先請 AI 修正交接狀態。

## 對你已有檔案的影響

本版不會自動覆寫你的 handoff 內容，也不會替你假裝已完成 closeout。`doctor` 會繼續指出需要修的交接結構；`upgrade` 只負責把「檔案已最新」與「交接狀態仍需核對」分清楚。

## 建議下一步

升級後如看到交接狀態提示，請執行：

```bash
npx --yes @adamchanadam/agent-handoff-kit@latest doctor
```

然後把輸出貼給 AI，請它先做 closeout 狀態核對，不要重裝或覆寫項目文件。
