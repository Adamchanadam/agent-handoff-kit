# v0.3.28

## 本版新加了甚麼

這版把「治理打通」改成更容易記的新手說法。你現在可以直接在 AI 對話中說：

```text
把 docs/production-guide.md 接入 Agent Handoff Kit
```

也可以掃描整個 repo 中可能漏接的重要文件：

```text
掃描未接入 Agent Handoff Kit 的重要文件
```

舊說法仍然保留：

```text
治理打通 docs/production-guide.md
bridge governance for docs/production-guide.md
scan for unbridged governance documents
```

## 對你已有檔案的影響

本版不會自動刪除、改名、移動或合併文件。掃描只會列出候選與缺口；你確認後，AI 才會按建議補丁更新索引、同步登記或相關流程。

既有項目升級時，工具會在可安全判斷時補上新版中文觸發語，並保留原有「治理打通」入口與本地自訂內容。

## 建議下一步

既有項目可直接升級：

```text
npx --yes @adamchanadam/agent-handoff-kit@latest upgrade
```

升級後照常在能讀寫本機資料夾的 AI 對話輸入 `Start Agent Handoff` 或「開工」。若新建了重要文件，可以說「把 <檔案> 接入 Agent Handoff Kit」。
