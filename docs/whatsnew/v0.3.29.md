# v0.3.29

## 本版新加了甚麼

這版新增一個專給 AI 讀的安裝／升級頁。新手不用先讀 README，也不用自己判斷要安裝還是升級；在目標資料夾打開能讀寫本機資料夾的 AI agent，貼上：

```text
請讀取 https://adamchanadam.github.io/agent-handoff-kit/agent-handoff-kit-ai-install.html，並在這個資料夾安裝或升級 Agent Handoff Kit。
```

AI 應先顯示目前資料夾並請你確認。未確認前，不應執行 `init`、`upgrade` 或 `doctor`。

## 長期治理更清楚

「接入 Agent Handoff Kit」仍然只指重要文件接合，目的是避免新建文件變成下一個 AI 找不到、不知道要更新的孤兒文件。

如果你想保存一條長期有效的做法，例如 API 用法、MCP 用法、工具操作規則，或把今次錯誤變成日後機制，AI 會改用長期治理入庫流程，找正確持久位置，而不是只寫入 session log 或 handoff。

## 對你已有檔案的影響

本版不會刪除、改名、移動或合併你的文件。HTML 安裝頁不會進入 npm package；它只是在 GitHub Pages 上給 AI 讀，用來引導本機安裝或升級。

既有項目升級時，工具會保留既有 handoff、log、index、decisions、rule packs 與本地自訂內容。

## 建議下一步

新手可先用 AI 安裝頁。已安裝舊版的項目仍可直接升級：

```text
npx --yes @adamchanadam/agent-handoff-kit@latest upgrade
```

升級後照常在能讀寫本機資料夾的 AI 對話輸入 `Start Agent Handoff` 或「開工」。
