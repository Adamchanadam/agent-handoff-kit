# v0.3.56

## 本版新加了甚麼

- `closeout-status` 若因 handoff lifecycle 擋住，現在會直接列出第一組相撞內容：已完成或已驗證的一行，以及仍被帶到下一輪的一行。
- `doctor` 的 handoff lifecycle 檢查收回成機械底線，只確認必要欄位與區段可讀；真正語義對賬仍由 `closeout-status` 負責。
- 單獨 `Start Agent Handoff` /「開工」的標題命名改為最後一步：先完成目前目標、風險／邊界與推薦下一步，再用這些已定稿事實命名當前對話。
- 支援安全當前對話標題控制的平台，不再因缺少標題讀回能力就放棄命名；但「開工」、「開始交接工作」等泛稱仍不能當主要動作。

## 對你已有檔案的影響

這版不新增命令，也不要求你手動改既有 handoff。升級後，收工被 lifecycle 擋住時，AI 可直接根據 `closeout-status` 顯示的第一組衝突修正 `SESSION_HANDOFF.md`，不用檢查 Kit 內部或把普通收工擴大成專案治理修補。

開工標題仍只屬 display-only：不是任務授權、進度、完成證據、健康結果或新的真源。不支援安全當前對話標題控制的平台會照舊略過。

## 建議下一步

發布後在已安裝 Agent Handoff Kit 的項目執行 `upgrade`，再跑 `doctor`。之後照常用「開工」接續，用「收工」保存交接；若 `closeout-status` 顯示 blocked，先照它列出的 `Resolved` / `Carry-forward` 兩行修 handoff。
