# v0.3.31

## 本版新加了甚麼

這版讓 AI 在跨資料夾修改、臨時腳本失敗、shell 引號錯誤、工具輸出被截斷時更不容易繼續盲試或過早下結論。

如果 AI 修改了目前 workspace 以外、但會影響你或下一個 agent 的 repo / output / runtime，交接時要留下外部影響提示。若本機腳本或解析器第一次出錯，AI 要先停下分清是哪一層失敗，做最小可重現檢查與語法檢查，再執行寫入。

本版也新增 public mirror QA，檢查公開流通版、GitHub Pages、維護者材料與 npm package 邊界沒有混在一起。

## 對你已有檔案的影響

本版不會刪除、改名、移動或合併你的文件。既有項目升級時，工具會保留既有 handoff、log、index、decisions、rule packs 與本地自訂內容。

升級後，核心 runtime 會取得跨 workspace 影響提示與長輸出讀取防護；安全規則包會取得 parser failure discipline。這些規則目標是減少 AI 在 Windows、macOS、Linux 或多層 shell 包裝下反覆試錯，並要求寫入後讀回受影響檔案。

## 建議下一步

已安裝舊版的項目可升級：

```text
npx --yes @adamchanadam/agent-handoff-kit@latest upgrade
```

升級後照常在能讀寫本機資料夾的 AI 對話輸入 `Start Agent Handoff` 或「開工」。
