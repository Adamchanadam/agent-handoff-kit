# v0.3.39

候選狀態：尚未發佈。這版讓日常開工更快，也把舊項目升級改成可回復、可核對的交易。

## 本版新加了甚麼

- 「開工」只接續目前 handoff；有明確任務便在同一回覆開始第一個安全步驟，不再先做新手路由判斷。
- 新手引導只在你明確要求教學，或讀完狀態仍沒有可執行目標時出現。
- 完整收工集中到按需載入的規則包，日常不用常駐讀取整套收工細節。
- 升級在真正寫檔前先完成離線驗證；中途失敗會精確回復本次交易改動。
- doctor 會交叉核對「已完成」與仍存在的待辦、風險及下次指令，避免只靠一句「已解決」假通過。
- `file://` 驗證失敗不會直接終止本機介面驗收；仍須按安全邊界嘗試短效 localhost 路徑。

## 對你已有檔案的影響

- 舊 v0.3.38 項目的必要新規則會以三方合併補入；非重疊自訂內容保留，重疊內容會安全停止，不會整份覆寫。
- 新增 `dev/rules/closeout.md`；`SESSION_HANDOFF` 會加入不重置的新手狀態欄位，`SESSION_LOG` 不再保存完整開場訊息副本。
- 正式 conflict 在任何治理目標、版本或 migration artifact 寫入前停止。

## 建議下一步

正式發佈後，先在目標專案執行 `upgrade --dry-run`，確認沒有 conflict，再執行正式 upgrade；升級後以 doctor 結果判斷整體項目健康。
