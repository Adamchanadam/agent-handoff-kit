# v0.3.5

## 本版新加了甚麼

- `upgrade` 補齊 `dev/RULE_PACKS.md` 時會保留用戶自訂 rows，不再用整份模板覆寫。
- 如 `dev/RULE_PACKS.md` 的 routing table 表頭已被改動，工具會回報衝突並停手，不會猜測合併。
- `doctor` 明確說明自己只檢查、不修改；版本不齊時會先建議 `upgrade --dry-run`。
- `init` / `upgrade` / `doctor` 的提示文字更清楚，方便非技術新手分清 Terminal 檢查與 AI 對話下一步。

## 對你已有檔案的影響

- 既有用戶內容應保留。
- `dev/RULE_PACKS.md` 只會補 Kit 需要的 routing rows；你自己新增的任務路由 rows 應保留。
- 如果你手動改過 routing table 表頭，升級可能會停在衝突狀態，等你或 AI 判斷怎樣合併。

## 建議下一步

- 已安裝舊版的專案，先執行 `npx @adamchanadam/agent-handoff-kit@latest upgrade --dry-run`。
- 預演結果沒有衝突後，再執行 `npx @adamchanadam/agent-handoff-kit@latest upgrade`。
- 升級後執行 `npx @adamchanadam/agent-handoff-kit@latest doctor`，確認狀態通過。
