# v0.3.11

## 本版新加了甚麼

本版把 v0.3.10 發佈後留下的用戶旅程檢查補成長期守門。重點不是增加新功能，而是把已驗證的首次安裝、升級、衝突停手與公開文件一致性，轉成每次發佈前都會跑的檢查。

## 對你已有檔案的影響

既有項目不用重裝。升級時若沒有需要合併的內容，工具不會假裝完成一件大事；若遇到不能安全判斷的衝突，會清楚停手並提示先處理衝突。舊版本升上來時，工具也會保留既有資料與本地規則。

## 建議下一步

升級前可先預演：

```bash
npx --yes @adamchanadam/agent-handoff-kit@latest upgrade --dry-run
```

如果預演沒有 conflict，再執行正式升級。升級後可用 `doctor` 檢查項目是否完整；第一次使用的新項目，仍按安裝後顯示的起步句進入 AI 對話。
