# v0.4.4

## 本版新加了甚麼

- 收工檢查會把已確認的交接狀態與另一項未完成工作分開判讀；同一項交接仍未解決時，仍會阻擋收工。
- Workspace Identity 現在可讀取 Markdown 表格內的 Git 身分，減少其他說明文字造成的誤判。

## 對你已有檔案的影響

- 既有交接和安全檢查不會自動改寫；真正未確認的收工狀態仍會明確顯示為阻擋原因。
- 本頁介紹 v0.4.4；可下載版本以 npm 發布記錄與 GitHub Release 為準。

## 建議下一步

升級後如收工被阻擋，保留訊息交給 AI 檢查對應欄位；如工作已確認完成，其他未完成工作可按原本計劃繼續處理。
