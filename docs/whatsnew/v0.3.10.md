# v0.3.10

## 本版新加了甚麼

改善第一次安裝後的實際使用流程。終端機完成安裝後，提示會更清楚地把「終端機動作」與「AI 對話下一步」分開；新手引導會用 5 步幫用戶選情境、問背景、收斂第一個小任務，再等用戶確認後才開始正式工作。

## 對你已有檔案的影響

本版會保留既有項目內容。升級時若發現 `CLAUDE.md` 被 AI 改成一份很長的規則文件，工具會把它恢復為短橋接檔，避免 Claude Code 把橋接檔當成第二套規則來源。`GEMINI.md` 也同步說明 Antigravity CLI 與 Gemini CLI 遷移期的入口關係。

## 建議下一步

升級前可先預演：

```bash
npx --yes @adamchanadam/agent-handoff-kit@latest upgrade --dry-run
```

確認沒有衝突後再升級。升級完成後，如你是第一次使用這個項目，請把工具顯示的完整起步句貼到 AI 對話，而不是留在終端機繼續操作；舊項目升級用戶則照原本開工方式繼續即可。
