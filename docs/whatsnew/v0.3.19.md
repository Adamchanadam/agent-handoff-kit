# v0.3.19

## 本版新加了甚麼

本版把公開開工說明改成短入口優先。若 AI agent 已經在正確專案資料夾內，日常只需說：

```text
Start Agent Handoff
```

或中文「開工」。

只有當 AI 還未指向專案資料夾時，才使用帶路徑啟動句：

```text
Work in <你的專案資料夾>. Read AGENTS.md first, then Start Agent Handoff. Before changing anything, tell me the current state and your recommended next step.
```

## 對你已有檔案的影響

升級會更新 README、CLI 安裝後輸出、介紹頁、操作指南、runtime closeout 說明與初始模板。既有用戶內容仍保留；真正接力內容仍由 `dev/SESSION_HANDOFF.md` 與 `START_NEXT_SESSION_PROMPT.txt` 承載。

本版不改變工具適用邊界：Agent Handoff Kit 仍只適合能讀寫本機專案資料夾的 agentic AI 長任務環境，不適合普通 web chat AI。

## 建議下一步

在已打開專案資料夾的 AI agent 中輸入 `Start Agent Handoff` 或「開工」。完成任務時仍說「收工」，讓 AI 更新交接文件與提示副本。
