# v0.3.17

## 本版新加了甚麼

本版把 `upgrade` 成功後的輸出縮短。工具不再把多個版本的完整版本說明直接印在終端機中，避免用戶在只想完成升級時被長篇內容打斷。

升級成功後，CLI 只會保留必要資訊：哪些檔案建立、合併或略過；升級已完成；下方會自動跑 `doctor`；如要看詳細版本內容，可稍後到 GitHub Release 查看。

## 對你已有檔案的影響

既有項目不用重裝。這次修補只改升級完成後的顯示文字，不改合併規則，不覆寫你的工作紀錄，也不改 `doctor` 判斷。

如果升級後自動檢查通過，你可以直接回到原本的 AI 工作對話繼續使用。

## 建議下一步

舊項目仍可先預演：

```bash
npx --yes @adamchanadam/agent-handoff-kit@latest upgrade --dry-run
```

如果預演沒有 conflict，再執行正式升級。升級後先看自動 `doctor` 是否通過；版本詳情不需要在升級當刻閱讀。
