# v0.3.12

## 本版新加了甚麼

本版修正 `doctor` 對下次開工提示便利副本的判斷。`dev/SESSION_HANDOFF.md` 仍是權威；`START_NEXT_SESSION_PROMPT.txt` 只是給你下次開工複製用的副本，應在收工 closeout 時重新產生。

## 對你已有檔案的影響

既有項目不用重裝。若你在一個 session 中途更新了 handoff，但還未收工，`doctor` 不會再因便利副本暫時落後而判定項目失敗。它會提醒你：完成任務後請 AI 執行 closeout，屆時再重生便利副本。

## 建議下一步

升級前可先預演：

```bash
npx --yes @adamchanadam/agent-handoff-kit@latest upgrade --dry-run
```

如果預演沒有 conflict，再執行正式升級。升級後可用 `doctor` 檢查；若只有便利副本提醒，繼續工作即可，收工時再讓 AI 保存交接。
