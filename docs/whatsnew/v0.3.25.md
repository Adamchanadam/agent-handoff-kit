# v0.3.25

## 本版新加了甚麼

這版讓 AI 在每個任務完成後的收尾動作更穩定。完成一個小步驟，不等於要立刻完整重寫整套交接文件；真正需要留下的，是下一個 AI 不能可靠重建、而且會影響之後工作的事實。

新的 runtime 會先分辨三種情況：沒有需要保存的新事實，就只回報結果；有新檔案、新真源、重要驗證結果或新決策，就按文件角色輕量保存；到了你明確說「收工」、需要交接、發佈、外部同步，或工具即將停止時，才做完整 closeout。

同時，公開 README 與兩個 HTML 介紹頁保持簡單，只保留用戶需要知道的操作路徑。內部分流規則留在 runtime 與 QA 裡，不要求新用戶先理解治理分類。

## 對你已有檔案的影響

既有項目升級後，原本的 handoff、session log、project index、decisions 與 rule pack 會按既有非破壞性策略保留。本版主要改的是 AI runtime 如何判斷任務後要不要保存、保存到哪裡、何時才完整收工。

如果工作中新增了本機檔案、刪除了檔案、加入了 URL 或本機來源，AI 應把它們登記到正確文件。若你指出 AI 的錯誤，並要求把經驗轉成長期機制，AI 應先找既有規則或決策文件合併，而不是只把經驗留在聊天紀錄。

若只是草稿、圖片或文稿仍在同一輪對話中反覆修改，AI 不應因此每一步都完整 closeout。

## 建議下一步

既有項目可直接升級：

```text
npx --yes @adamchanadam/agent-handoff-kit@latest upgrade
```

升級後照常在能讀寫本機資料夾的 AI 對話輸入 `Start Agent Handoff` 或「開工」。本輪工作真正要結束時，再輸入「收工」或 `Wrap up Agent Handoff`。
