# v0.4.5

## 本版新加了甚麼

- AI 第一次執行新寫或改過的程式前，須先另外讀清楚用法，留意參數、環境變數、刪除及覆寫；如可能刪除或覆寫它自建暫存位置以外的內容，須先確認工作可復原（已提交、已備份或在隔離副本執行），否則先問你。
- AI 自己寫的測試和輔助腳本只可清理它自建的暫存位置；核實不到目標便停止並回報失敗。
- 部分規則說明刪去重複字句，規則要求不變。

## 對你已有檔案的影響

- 升級會更新已安裝的規則正文，包括 `dev/rules/coding.md`；你寫在 `## Project Rules` 之後的專案附錄會保留。
- 如規則正文曾在本機被改動，升級會停手而不寫入檔案，可交給 AI 協助處理。
- 新規則是 AI 執行程式前的工作要求，用來減低誤刪風險；重要工作仍建議保持提交或備份。
- 本頁介紹 v0.4.5；可下載版本以 npm 發布記錄與 GitHub Release 為準。

## 建議下一步

升級後照常工作即可。AI 執行新寫或改過的程式前，應先按新規則閱讀用法及確認適用的復原條件；這些規則本身不授權提交或備份。
