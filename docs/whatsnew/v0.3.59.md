# v0.3.59

## 本版新加了甚麼

- `doctor` 會先確認 `AGENTS.md` 和 `dev/USER_RULES.md` 的接受紀錄是否一致。
- 如果接受紀錄不一致，它會先停下並指出問題，不再叫 AI 用一般 anchor 修補去改受管核心。
- 發佈驗收加入同一情境的回歸檢查，避免未來再把這類見證錯誤誤判成普通缺段。

## 對你已有檔案的影響

這版不會自動改寫你的 user rules。若 `doctor` 報 `AGENTS.md` 與 `dev/USER_RULES.md` 的接受紀錄不一致，請不要手動補 `AGENTS.md` managed core anchor，也不要覆寫 `dev/USER_RULES.md`。

正確方向是先還原已接受的 managed core，或讓正式 upgrade transaction 重新建立完整的 user-rules 接受紀錄。

## 建議下一步

發布後在受影響項目執行 `doctor`。若看到 user-rules 接受紀錄錯誤，保留完整輸出交給能讀寫該資料夾的 AI；不要只按缺失 anchor 手修。
