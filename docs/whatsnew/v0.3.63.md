# v0.3.63

## 本版新加了甚麼

- 「教我用 Agent Handoff Kit」現在會先用普通用戶語言列出可直接叫 AI 做的事情，例如開工、收工、接入文件、掃描未接入的重要文件、把錯誤沉澱成日後規則、保存 API / 工具用法，以及外部工具資源收口。
- 教學回答會展示 fenced `text` 小貓 quick guide 卡，讓 ASCII spacing 穩定；這張卡只是教學提示，不會冒充已開工、已讀 handoff、已通過 doctor 或已保存交接。
- CLI 維護指令仍保留，但放在次要位置；新手不需要先理解 `init`、`upgrade`、`doctor` 才知道 Kit 能做甚麼。
- 長期治理加入「同類錯誤復發」路由：若 AI 已聲稱修好某類錯誤但它又復發，下一輪要先回到真正 owner、反例與重播驗收；必要時才分離修改與驗收角色。
- 這條復發規則只限制出錯領域，不建立中央懲罰庫、黑名單或永久停權，也不把單一專案事故細節帶入 public Kit。

## 對你已有檔案的影響

升級不會改寫你的工作內容。影響主要在 AI 的回答與判斷：新手問「教我用」時會看到較完整的自然語言口令；同類錯誤復發時，AI 會用更受限、更可驗證的方式根修，而不是把責任藏在 handoff 或只追加一條提醒。

普通任務不會因此變重。沒有錯誤復發、沒有長期規則沉澱、沒有 closeout / release / 外部副作用時，仍按任務本身做局部驗收。

## 建議下一步

發布後在已安裝 Agent Handoff Kit 的項目執行 `upgrade --dry-run`，確認沒有 conflict，再執行 `upgrade --yes` 和 `doctor`。之後可以在 AI 對話直接問「教我用 Agent Handoff Kit」檢查新手導覽是否清楚。
