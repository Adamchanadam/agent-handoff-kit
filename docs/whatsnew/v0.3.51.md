# v0.3.51

## 本版新加了甚麼

- `doctor` 和 `closeout-status` 不再把普通專案根目錄檔案當成 Kit current-state 權威。
- Gate 5 仍會記錄 whole-root discovery 作為安全證據，但 protected source-conservation witness 只綁定有 Kit reachability、transaction、archive migration 或 installed contract coverage 的項目。
- 舊 v0.3.46-style all-root witness 可以安全 rebind；只有已證明 outside-known、沒有 reader、沒有已知 effect 的普通 root-source entry 可退休。
- 有 reader、非 outside-known metadata、rule-pack、formal-route、managed-core 或 archive / state coverage 的 entry 仍 fail closed，不能被普通 root-source 捷徑靜默接受。

## 對你已有檔案的影響

普通 README、CHANGELOG 或其他 user-owned project files 的後續變更，不應再令 Kit 的 current-state witness 永久卡住。Kit-managed rules、formal routes、archive migration 和 closeout state 仍維持原本的保守驗證，不會因本修補而放寬。

## 建議下一步

維護者發布前必須先完成 candidate-preflight、乾淨 freeze、獨立 evidence review、formal full gate、release-decision review，以及後續另行授權的 push / tag / npm / GitHub Release / postpublish readback。一般使用者只需繼續使用 `@latest`；若遇到 upgrade 或 closeout blocked，保留輸出並交給能讀寫該資料夾的 AI 判斷。
